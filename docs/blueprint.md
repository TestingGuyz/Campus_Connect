# **App Name**: CampusConnect

## Core Features:

- User Authentication: Secure login and logout functionality for both admin/teachers and students.
- Role-Based Dashboards: Separate dashboards for admins/teachers and students upon login.
- Interactive Groups: Differentiated access to Groups feature with 'Teachers' and 'Parents' sections for communication.
- Calendar Events: Admin-managed calendar for important events, and personal calendar events for students.
- Attendance Tracking: Attendance marking system for teachers to mark students present, absent or late.
- Student Profiles: Centralized repository for student details, academic records, and extracurricular performance.
- Assignments and Resources: Teachers can upload study materials, event details, and downloadable content for students.
- Time Table Display: Digital timetable for students to view their daily class schedule.
- Contact Admin: A tool powered by a generative AI model allows the user to automatically and securely inform administrators regarding any problems faced in the application. LLM model chooses whether and when to include specific problem details when formatting the issue.

## Style Guidelines:

- Primary color: Shades of red (#E57373) to convey a sense of importance and energy, aligning with traditional academic colors.
- Secondary color: Shades of blue (#64B5F6) to bring a calm, trustworthy feel for informational elements and interactions.
- Background color: Light gray (#FAFAFA) to provide a clean and neutral backdrop, ensuring readability and focus.
- Accent color: A more saturated blue (#2979FF) to highlight key actions and interactive elements.
- Body and headline font: 'PT Sans' (sans-serif) will be used throughout the app for its modern, yet approachable and readable design.
- Consistent use of flat, modern icons to represent different sections and actions, ensuring easy recognition.
- Clean, intuitive layout with clear section separation and logical content placement.
- Subtle transitions and loading animations to provide a smooth user experience.
